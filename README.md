# Сайт Агропромпарка «Южный»

Статический сайт без сборки: `index.html` (главная) и `magazin.html` (магазин одежды).
Чтобы посмотреть, откройте `index.html` в браузере. Для публикации залейте всю папку на любой хостинг.
