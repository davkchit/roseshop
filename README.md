# Сайт Агропромпарка «Южный»

Статический сайт без сборки: `index.html` (главная) и `magazin.html` (магазин одежды).
Чтобы посмотреть, откройте `index.html` в браузере. Для публикации залейте всю папку на любой хостинг.

## Файлы

- `assets/css/style.css`: весь дизайн (цвета в `:root`)
- `assets/js/app.js`: меню, параллакс, карусель, схема рынка, фото-тур, просмотр фото жестами
- `assets/img/hero.jpg`: главный экран; `assets/img/store/*.jpg`: фото магазина

Новая карточка товара: положить фото в `assets/img/store/` и скопировать любой блок `<article class="pcard">`
на странице раздела (`dzhinsy.html`, `hudi.html`, `pizhamy.html`): поменять фото, название, описание и текст в ссылке WhatsApp.

## Отступы

Правила отступов записаны комментарием в начале `style.css`. Все отступы берутся из шкалы на 4 px в начале `style.css` (`--s1`…`--s8`, плюс `--gap`, `--section-pad`, `--head-gap`
и другие). Новые числовые значения для `padding`, `margin` и `gap` вручную не писать.

## Фото-тур

На странице `magazin.html` (блок «Как нас найти?») шаги тура — это список `<ol data-tour-steps>`.
Для каждого шага: `data-img` (фото), `data-x` и `data-y` (где метка, в процентах кадра), `data-label` (текст метки),
необязательно `data-zoom` (приближение). Новые фото кладите в `assets/img/` и меняйте `data-img`; код не трогаем.

## Цвета

Весь сайт держится на одном тёплом оттенке: `--warm` / `--bg` / `--surface-sun` равны `#fbecd9`. Новые цветные заливки делать только им.
